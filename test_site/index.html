Broken Link Automation Test Page

Local demo website for the Automated Web Broken Link Detection and Reporting System.

Every link on this page is intentional. Run python run.py --url http://localhost:8000 and compare the generated report with the expectation badge of each section below.

1. Working link expect 200 WORKING

  • http://localhost:8000/about.html

2. Broken link expect 404 CLIENT_ERROR

  • http://localhost:8000/does-not-exist

3. Redirect link expect 302 REDIRECT

  • http://localhost:8000/redirect  (302 → /about.html)

4. Internal link expect 200 WORKING

  • about.html  (relative URL, the detector resolves it to http://localhost:8000/about.html)

5. External link expect 200 WORKING (needs internet)

  • https://example.com  (external domain; skipped when running with --no-external)

6. Duplicate links checked once, occurrences reported

  • http://localhost:8000/about.html  (duplicate #1)
  • http://localhost:8000/about.html  (duplicate #2)

7. Skipped links expect SKIPPED - never requested

  • mailto:test@example.com  (mail link, not checkable over HTTP)
  • javascript:void(0)  (JavaScript link, never requested)
